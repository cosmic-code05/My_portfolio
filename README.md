My personal portfolio website, built using **HTML, CSS, and JavaScript**.

This was the **first ever website I built from scratch**, so this project is especially meaningful to me. It was my first step into actually creating something instead of just learning concepts.

## Built With

* HTML
* CSS
* JavaScript

I built this portfolio while learning the fundamentals of web development. From designing the layout and styling the pages to adding interactive elements with JavaScript, everything was built as part of my learning process.

It started as a simple project and gradually evolved as I learned more and experimented with different ideas.

This repository represents the **beginning of my journey into building things on my own**.
